# Unreleased — current stateless MCP lane beside the legacy handshake era

## Fixed

- Browser clients can now preflight the modern MCP routing headers:
  the MCP admission boundary's CORS allow-list answers `Mcp-Method` and
  `Mcp-Name` beside `MCP-Protocol-Version` without widening origins,
  Host, audience, or quota policy (ADR 0272).

## Added

- The MCP resource server serves the current 2026-07-28 stateless
  revision and the legacy handshake revisions from the same pinned
  official SDK app. Modern requests are self-describing, need no
  `Mcp-Session-Id`, and may use `server/discover`; a `Mcp-Method` or
  `Mcp-Name` mismatch fails closed before any tool call or quota unit.
  Legacy `initialize` clients keep working through the deprecation
  window (ADR 0272).
- The k6 MCP E2E harness now runs the stateless modern lane by default
  with JSON-RPC identity validation for every observed reply; the
  2025-11-25 handshake remains an explicitly named compatibility lane
  through the same script.
