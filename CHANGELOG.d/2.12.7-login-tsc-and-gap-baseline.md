# Unauthenticated login no longer breaks the frontend typecheck

- Login uses the existing OIDC return-URL helpers so a validated path,
  query, and fragment survive the SSO round-trip and persist to the
  session/local storage fallback consumed by the callback.
- The unauthenticated shell no longer mounts Admin settings with an
  undefined access token. That mismatch failed `tsc -b` on protected
  `main` and on every PR that inherited the login path.
- Restores a non-identifying product/technical gap baseline bound to the
  current PR and issue inventory (ADR 0001). Identifying post identifiers
  must not return to this file.
