# Dashboard replaces the Board as the `/` landing route

`/` now opens a news-portal Dashboard ranking important posts and important
projects by real `fast-mlsirm` FIPC-calibrated theta (falling back to
RankWeave's fused ranking before any project period report exists), instead
of the Board's find-and-filter list. The Board stays one click away as the
first Workspace navigation item after Dashboard (ADR 0145).
