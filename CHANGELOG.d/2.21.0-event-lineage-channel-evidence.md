## Changed

- Missing reconstruction channels are now shown as unavailable rather than fabricated as zero.
- Edges with no persisted channel evidence no longer claim that LLM adjudication
  was absent; the Buyer sees unavailable metadata until evidence exists.
- The Event Lineage API now keeps fused ranking, channel evidence, source authorization, public verification, and TEPP/fast-mlsirm measurement as distinct contracts.
- A rebuild now validates the complete active profile before its first database write and rejects unknown, non-finite, out-of-range, mismatched, or non-reconciling evidence.
- Migration 0055 is applied by Docker and backend integration fixtures and is safe to reapply.
