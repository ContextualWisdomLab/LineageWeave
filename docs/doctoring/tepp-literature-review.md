# TEPP literature review and LineageWeave evidence map

Reviewed against the local TEPP `standards-and-literature.md`, all task-level
research doctoring references used by the current TEPP documentation, PRD v0.4,
LLM-orchestration contract, temporal/event ADRs, and the local
contextual-orchestrator research notes. This file keeps the APA 7th register in
the product documentation so a product claim does not depend on an operator
remembering an external checkout. It records implementation boundaries; it is
not a claim that LineageWeave has become TEPP's Rust estimator.

## Implementation disposition

- Direct PostgreSQL lineage and customer-master views implement evidence,
  provenance, temporal separation, authorization, and normalized semantic rows.
- DOM structure, formatting hints, asset positions, strict raster validation,
  OCR/object descriptions, and digest-bound inspection implement the multimodal
  boundary. Raw HTML/base64/image bytes are not embedding inputs or graph JSON.
- Reports persist one normalized observation per time window and delegate the
  psychometric linking boundary to the separate fast-mlsirm connector. This
  product does not claim to implement TEPP's Rust/GPU estimator.
- Keyman, evidence verification, chat, and report judging carry model/role/
  evidence metadata over HTTP. Direct versus composed work remains a bounded
  experimental variable; an empty or unsupported answer is an abstention.
- The four multimodal papers were added to `OA_METHOD_PAPERS` and are stored
  through the same Local Zotero metadata/original-attachment path as the TEPP
  method references. The code records attachment outcome and SHA-256; a Zotero
  write is not treated as proof of a paper's scientific claim.
